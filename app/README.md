# Демо «Линия 1: прогноз нагрузки» (локально)

Интерфейс диспетчера + эмулятор, который проигрывает **реальные рабочие дни** из данных турникетов (15 минут).
Для дня месяца M используется модель, **не видевшая месяц M при обучении** (честный прогноз вне выборки).

## Запуск
```bash
pip install -r app/requirements.txt
python -m uvicorn app.server:app --port 8000      # из корня репозитория
```
Открыть http://localhost:8000 (старый интерфейс: `/classic`). Модели лежат в `app/models/`, переобучить: `python app/train_models.py`.
Данные берутся из `data/processed_15min_line1.parquet` и `data/weather_spb_2026.parquet`.

## Что показывает
- Карта линии: загрузка перегонов по двум направлениям (прогноз на ближайший час), отклонение станций от нормы (порог 20%).
- Одно главное действие: сколько составов добавить или что делать, откуда из депо, когда дать команду, почему.
- График входа по линии: факт, прогноз, норма.
- Станция по клику: прогноз по направлениям и причины.

## Эмулятор (панель сверху, клавиша E скрывает)
Сценарии: реальные 13 февраля и 11 сентября (утренний пик у предела), обычный вечер (система молчит), вбросы «событие у центра» и «сбой на другой линии».
Кнопки «+ Событие» и «+ Сбой» добавляют синтетический рост входа в будущие слоты текущего дня.

## Как считается (коротко)
1. Прогноз входа по 19 станциям на 2 часа: LightGBM (календарь, лаги ≥30 мин, вчера, неделя), рекурсивно; на ближайший час смешан с «инерцией» последних 30 минут (WAPE станции за час 5,42% против 5,86% у модели).
2. Норма: медиана последних 4 таких же дней недели (запасная — из других месяцев).
3. Нагрузка перегонов по направлениям: упрощённая модель корреспонденций (затухание по расстоянию, средняя поездка 6 перегонов), масштаб откалиброван так, что пик плана = 85% комфортной вместимости.
4. Решение: нагрузка прогноза ≥88% комфортной вместимости (120 чел/вагон) и ≥+8% к норме ⇒ добавить поезда; если интервал уже на пределе (113 с), система говорит об этом и предлагает другие меры. Резерв: 5 мин готовность + 7–8 мин ход + перегоны.
5. Допущения (вместимость, средняя поездка, калибровка пика) нужно подтвердить у метро.
